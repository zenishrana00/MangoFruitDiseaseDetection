      Mango Fruit Disease Detection

      A college academic machine learning project demonstrating transfer learning and computer vision using TensorFlow, Keras, and EfficientNetB0 for agricultural disease screening.

      Technical Specifications

      • Model: EfficientNetB0 (ImageNet Transfer Learning)
      • Dataset: Amrapali Mango Fruit Diseases
      • Validation / Test Accuracy: ~93.33%
      • Frameworks: Python, Flask, TensorFlow, Keras, NumPy, Pillow
